# Segurança e privacidade

Este repositório contém documentação e exemplos fictícios. Ele não deve receber cupons reais, listas pessoais, links privados do Google Drive ou cópias da planilha em uso.

## Dados que ficam fora do repositório

- CPF e outros documentos;
- endereço, telefone ou dados de contato;
- informações de pagamento;
- cupons e notas reais;
- fotos feitas durante compras;
- links privados do Drive e da planilha;
- credenciais, chaves e tokens.

O processamento deve se limitar aos campos necessários para identificar o produto, comparar os preços e registrar a evidência. Caso uma imagem contenha dados pessoais, eles devem ser ignorados ou removidos antes de qualquer compartilhamento.

Se encontrar um dado real publicado por engano, não abra uma issue com esse conteúdo. Avise o responsável pelo projeto de forma privada para que o histórico seja corrigido.
